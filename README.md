# 《月根秘境》

一款“农作物魔法 × 房间制 Roguelike”的原创 C# 像素动作游戏。

当前仓库已经包含使用 Godot .NET 与 C# 制作的首个可玩原型。

## 当前可玩内容

- 五个连续战斗房间与“灯笼南瓜王”Boss。
- 键鼠与基础手柄操作。
- 芽弹射击、翻滚与晨露圈技能。
- 播种、湿润加速、植物成长、自动攻击和范围收割。
- 泥团芽、刺萝卜、壳豆虫与 Boss 四类敌人。
- 房间奖励、资源拾取与三选一局内升级。
- 标题、HUD、暂停、失败和胜利界面。
- 程序化生成的复古游戏音效，无外部音频依赖。

## 操作

| 行为 | 键鼠 | 手柄 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 |
| 瞄准 | 鼠标 | 右摇杆 |
| 芽弹 | 鼠标左键 | 右肩键 |
| 播种 | 鼠标右键 | 左肩键 |
| 翻滚 | Space | A |
| 收割 / 进入根门 | E | X |
| 晨露圈 | Q | Y |
| 暂停 | Esc | Start |

植物完全成熟后会自动攻击。靠近成熟植物按 E 可以收割，对周围敌人造成范围伤害。湿润地块上的植物成长得更快。

## 开发环境

- Godot 4.7.1 .NET
- C# / .NET 8
- Visual Studio 2022 或其他兼容 C# IDE

本地运行：使用 Godot .NET 打开仓库根目录中的 `project.godot`，或通过 Godot 控制台执行：

```powershell
Godot_v4.7.1-stable_mono_win64_console.exe --path .
```

## Windows 构建

在本地工具与导出模板准备完成后，可执行：

```powershell
.\Scripts\build-windows.ps1 -Configuration Release -Installer
```

脚本会先编译 `Moonroot.sln`，再导出 Windows x64 版本；带 `-Installer` 时还会调用 Inno Setup 生成安装程序。产物位于：

- `builds/windows/`：Godot Windows 导出目录。
- `builds/installer/MoonrootSetup-x64-v0.1.0.exe`：支持简体中文和英文的安装程序。

仓库中的 `tools/`、`.godot/` 和 `builds/` 均为本地生成目录，不会提交到版本控制。
