# 《月根秘境》多房间关卡与战斗扩展设计方案

版本：玩法扩展设计 v0.2  
状态：设计提案，仅用于确认玩法方向，本阶段不涉及开发  
关联文档：《游戏设计文档》《首版内容与数值草案》《美术与 UI 规范》

---

## 1. 本次改版目标

当前原型是 4 个普通战斗房接 1 个 Boss 房的线性流程，能够验证移动、射击、播种、湿润和收割，但还不足以支撑完整 Roguelike 的探索与重复游玩。

本次改版将流程调整为：

> 进入一个由多个房间组成的区域 → 自由探索分支 → 获取武器、遗物和补给 → 找到 Boss 房 → 击败区域 Boss → 穿过季门进入风格完全不同的下一关。

核心目标：

1. **每关都有真正的探索感**：不是按顺序打固定数量的房间，而是在房间网络中寻找 Boss。
2. **四关体验明显不同**：每关拥有独立的色彩、音乐、地形规则、陷阱、敌人和 Boss。
3. **难度逐关升级**：主要增加敌人组合、攻击角度、弹幕形态和地形压力，敌人生命只做温和增长。
4. **武器改变操作方式**：加入近战、激光、扇形弹幕等武器，不让武器只表现为射速和伤害的区别。
5. **保留本作特色**：所有武器、陷阱与关卡机制都要能和“播种—生长—收割—土地状态”发生联系。

### 1.1 不采用的方向

- 不做无缝大地图，仍然使用短促、可控的房间制战斗。
- 不要求清空一关的全部房间，允许玩家在风险和收益之间取舍。
- 不用大量加血制造后期难度，不让普通敌人成为“血包”。
- 不照搬其他游戏的角色、房型、道具、美术和 Boss 招式，只借鉴房间探索、即时战斗和局内构筑的类型框架。

## 2. 完整单局结构

### 2.1 推荐流程

营地选择角色、主武器和起始种子：

1. 第一关：春·苔灯地窖
2. 第二关：夏·蜂鸣温室
3. 第三关：秋·落穗磨坊
4. 第四关：冬·静月根庭
5. 击败最终 Boss，进行结算并返回营地

击败区域 Boss 后，角色的生命、武器、种子、遗物和构筑全部保留。玩家会恢复 2 点生命并补充 1 个种荚，但不会完全恢复，保证跨关资源管理有意义。

### 2.2 时长目标

| 内容 | 目标时长 |
|---|---:|
| 单个普通战斗房 | 35–65 秒 |
| 精英房 | 60–90 秒 |
| 单个区域（含 Boss） | 8–11 分钟 |
| 区域 Boss | 2.5–4 分钟 |
| 完整单局主路线 | 35–45 分钟 |
| 深度探索支路 | 最多约 50 分钟 |

玩家不需要每次探索全部房间。熟练玩家可以直奔 Boss，构筑较弱时也可以主动寻找商店、温室和精英奖励。

### 2.3 开始新游戏与继续游玩

主菜单固定提供以下入口：

1. **开始新游戏**：选择难度、角色、主武器和起始种子后创建新单局。
2. **继续游戏**：存在有效单局存档时启用，显示当前关卡、难度、角色和累计游玩时间。
3. **积分榜**：查看所有已死亡或完成最终关的单局记录。
4. **设置**。
5. **退出游戏**。

如果已有进行中的单局，选择“开始新游戏”必须二次确认。旧单局会进入“放弃记录”，但不进入正式积分排名。

继续游戏不会改变已选难度、地图种子、房间布局、构筑、生命、货币和累计时间。详细存档规则见第 15 节。

## 3. 多房间地图结构

### 3.1 每关规模

每个区域生成 12–15 个房间，玩家通常会进入其中 7–10 个。

推荐房间构成：

| 房间类型 | 每关数量 | 作用 |
|---|---:|---|
| 入口房 | 1 | 安全出生、展示本关主题 |
| 普通战斗房 | 5–7 | 基础战斗、资源和构筑进度 |
| 精英房 | 1 | 高风险遗物奖励 |
| 功能房 | 3 | 从商店、温室、事件、休息中抽取 |
| 宝藏房 | 1 | 武器、遗物或稀有种子 |
| Boss 房 | 1 | 本关终点 |
| 隐藏房 | 0–1 | 约 25% 概率出现，不计入主路线 |

### 3.2 地图生成规则

地图不是规则的直线，也不是完全随机地拼接，生成时必须满足以下约束：

- Boss 房与入口房的最短距离为 5–7 个房间。
- Boss 房不能直接连接入口、商店或休息房。
- 地图至少存在 1 个环路，避免所有路线都成为死胡同。
- 地图包含 2–3 条明显支路，至少一条通向稳定补给。
- 主路前 3 个房间内必定出现一次构筑奖励。
- 不连续生成 3 个以上的强制战斗房。
- 精英房不会成为进入 Boss 房的唯一必经路线。
- 隐藏房入口通过墙缝、飘动叶片和低频音效提示，不依赖盲目炸墙。

示意地图：

```text
                   [宝藏]
                      |
[入口]—[战斗]—[温室]—[战斗]—[未知]
          |             |        |
        [事件]—[战斗]—[商店]—[Boss]
                   |
                 [精英]—[隐藏]
```

### 3.3 找到 Boss 的规则

- Boss 房在未探索地图上显示为普通的“未知根结”，玩家必须走到相邻房间后才会确认其位置。
- 不设置强制 Boss 钥匙。找到 Boss 后即可挑战，避免玩家发现 Boss 却还要机械地搜索钥匙。
- 每关存在 0–2 个可选的“季节根结”。净化根结会削弱 Boss 的一项场地优势，或提高 Boss 奖励质量。
- 季节根结只鼓励探索，不阻止速通。

例如：

- 净化春季根结后，南瓜王阶段三少生成一条封路藤蔓。
- 关闭夏季过热阀后，蜂箱母机的激光扫射转速降低。
- 卡住秋季主齿轮后，收割傀儡的传送带会周期性停转。
- 点亮冬季月灯后，最终 Boss 的延迟弹幕会提前显示安全缺口。

### 3.4 房间进入、清除与返回

- 首次进入战斗房后房门关闭，敌人分 1–2 波出现；只有挑战房允许 3 波。
- 清房后所有门永久打开，地图记录房间类型和未拾取奖励。
- 返回已清除房间时不再刷新敌人。
- 已清房间内玩家移动速度提高 25%，危险陷阱停止运作，减少无意义赶路。
- 清房后玩家可以立即收割全部成熟植物，也可以选择其中一株“留下根系”。
- 每个战斗房最多保留一个根忆节点；节点不再离屏攻击、成长或产出资源，防止刷取。
- 留根后其余植物正常结算并消失，被选植物转化为地图节点，不再获得本次即时收割收益。
- 根忆节点在本关内永久生效。温室房每关提供一次免费移栽机会，之后不能通过反复进出房间刷新选择。
- 返回已清房间时会看到节点的休眠形态和影响范围，但不能重复收割。

### 3.5 小地图信息

- 已探索房间显示完整类型、门和未拾取物。
- 相邻未探索房只显示模糊线索，如温暖灯光、商人铃声、蜂鸣或 Boss 心跳。
- Boss 被发现后用独特的大型根冠图标标记。
- 地图界面同时显示本关已净化的季节根结数量。
- 根忆节点使用图形符号显示标签，并用发光根线连接相邻节点。
- 相邻未知房会显示已知天气图标，但不会提前显示敌人和完整房型。
- 地图侧栏显示已激活生态配方，以及再连接一个节点可能完成的候选配方。

### 3.6 月根网络、天气与生态配方

月根网络是本作区别于普通房间制肉鸽的主要系统：

1. 清除战斗房后选择立即收割或留下根系。
2. 留下的根系使房间成为带标签的根忆节点。
3. 相邻节点通过房门形成根线，影响下一批未清除房间。
4. 三个相连节点满足条件时形成生态配方。
5. 进入 Boss 房时，当前网络转化为场地援助、风险和积分倍率。

根忆节点采用八个统一标签：

| 标签 | 对相邻房间的主要影响 | 风险或代价 |
|---|---|---|
| 湿润 | 初始出现湿地，植物成长更快 | 电与蒸汽攻击也会扩散 |
| 燃烧 | 第一次主动收割附带燃烧爆发 | 生成少量灼热地 |
| 孢子 | 植物效果会向附近目标传播 | 敌方孢子区持续更久 |
| 扎根 | 生成掩体、稳定风向或开启藤蔓捷径 | 可行走面积略微减少 |
| 月照 | 提高变异与稀有奖励概率 | 增加一项可预警的额外威胁 |
| 腐化 | 提高积分和资源倍率 | 强化敌人或场地机关 |
| 收割 | 清房后的即时资源增加 | 节点本身战斗援助较弱 |
| 附着 | 苗印和寄生效果可继续传播 | 附着型敌人也会获得强化 |

基础生态配方：

| 配方 | 三节点标签 | 效果 |
|---|---|---|
| 雨后菌环 | 湿润 + 孢子 + 附着 | 首株成熟植物会向两个目标传播效果 |
| 焦土轮作 | 燃烧 + 扎根 + 收割 | 主动收割产生范围爆发，并恢复少量种荚 |
| 月镜花圃 | 月照 + 湿润 + 扎根 | 生成一次可被玩家利用的折射镜花 |
| 寄生回春 | 腐化 + 孢子 + 附着 | 治疗溢出转为寄生护盾，但提高敌人生命 |
| 风中种路 | 孢子 + 扎根 + 收割 | 打开一条单向藤蔓捷径，并提高回收型攻击 |
| 饥土丰仓 | 连续两个收割节点 + 任意风险节点 | 当前资源大幅增加，但 Boss 少获得一个友方花圃 |

完整版本目标为 12–16 个生态配方，首个可玩切片只验证 4 个。

天气规则：

- 进入每关时显示本关天气序列和相邻未知房的天气图标。
- 天气至少提前一个房间可知，玩家可以据此选择路线和留根标签。
- 天气改变土地与弹体，不直接提供无法规避的全局伤害。
- 同一关最多同时存在一个主天气和一个根系修正，避免规则叠加失控。
- 天气预报在生成地图时固定，继续游戏不会刷新。

## 4. 房间类型与选择价值

| 房间 | 内容 | 玩家决策 |
|---|---|---|
| 普通战斗房 | 1–2 波敌人和少量场地机制 | 稳定获得月露、种荚和构筑进度 |
| 精英房 | 强化敌人组合或特殊规则 | 承担受伤风险换取遗物 |
| 商店房 | 补给、遗物、武器和地图情报 | 消费月露，决定立即变强还是保留货币 |
| 温室房 | 更换主种子、升级土地配方、治疗植物 | 调整构筑方向 |
| 事件房 | 交易、挑战、角色与世界叙事 | 做风险收益选择 |
| 休息房 | 恢复 2 点生命，或强化当前武器一次 | 生存与成长二选一 |
| 宝藏房 | 武器架、稀有遗物或季叶 | 获得明显的玩法变化 |
| 隐藏房 | 特殊事件、诅咒遗物或大量资源 | 奖励观察和探索 |
| Boss 房 | 独立场景和多阶段 Boss | 完成本关并获得季节祝福 |

普通战斗房不再每次都弹出三选一，以免打断节奏。建议每清除 3 个战斗房触发一次“芽变三选一”，其他房间主要掉落资源和即时补给。

## 5. 四个关卡主题

### 5.1 第一关：春·苔灯地窖

**体验定位**：学习探索、基础敌人组合、湿润土地和可利用陷阱。  
**视觉**：深蓝石墙、嫩绿苔藓、木架、土壤和暖橙色灯笼。  
**音乐**：木琴、拨弦和滴水声，节奏舒缓但有明确战斗拍点。  
**场地规则**：漏水会形成湿润地，湿地加快植物生长，也会略微降低急转速度。

敌人：

- 泥团芽：追踪并短跳，负责逼迫移动。
- 刺萝卜：蓄力后三连直射，负责远程压制。
- 壳豆虫：直线冲撞，可撞碎掩体。
- 偷苗鼠：优先啃食成熟植物，制造保护与收割的取舍。
- 月菇伞：布置延迟孢子区。
- 浇壶精：湿润或腐化局部土地，改变战场。

本关主要陷阱：

- 藤根突刺：地面鼓起 0.9 秒后刺出。
- 松动石块：阴影出现后落下，可砸伤敌人。
- 泥洼：降低移动速度，但能催化湿润类植物。

Boss：**灯笼南瓜王**。

---

### 5.2 第二关：夏·蜂鸣温室

**体验定位**：提高移动节奏，引入持续激光、曲线弹和灼热区域。  
**视觉**：金绿色玻璃温室、强烈日斑、蜂蜡、铜管和过度生长的藤蔓。  
**音乐**：快速拨弦、手鼓和带节奏的蜂鸣低音。  
**场地规则**：日照地会让植物快速生长，但停留过久会进入“焦熟”，自动爆发并留下短暂灼热区。

敌人：

- 花粉侦蜂：绕玩家弧线飞行并发射曲线弹。
- 蜂蜡卫兵：举盾阻挡正面攻击，需要绕后或利用穿透。
- 铃蕊花：周期性释放带安全缺口的环形花粉。
- 玻璃蜗牛：短时间折射弹体，击碎外壳后失去能力。
- 园丁胡蜂：标记落点后高速俯冲。
- 育巢工蜂：修复蜂巢柱或强化其他敌人。

本关主要陷阱：

- 聚光镜：预先显示亮线，随后缓慢扫出高热光束。
- 蒸汽阀：喷口先抖动并变红，再喷出直线蒸汽。
- 捕虫藤：叶片张开后咬住经过的单位，玩家和敌人都会受到影响。

Boss：**失控蜂箱母机**。

---

### 5.3 第三关：秋·落穗磨坊

**体验定位**：引入强制位移、方向改变和交叉火力，要求玩家规划移动路线。  
**视觉**：琥珀麦尘、红叶、旧木梁、铜色齿轮和旋转风车。  
**音乐**：机械打击乐、手风琴和低沉木管，节奏像不断加速的机器。  
**场地规则**：风向会周期性改变，轻微推动玩家、敌弹和未扎根的种子；成熟植物可以成为临时锚点。

敌人：

- 稻草枪兵：保持中距离，连续刺击并封锁窄路。
- 谷蛾群：分散时威胁低，聚集后形成扇形弹幕。
- 齿轮鼠：沿墙快速移动并放出反弹齿片。
- 糠炮桶：发射慢速大弹，大弹破裂为十字小弹。
- 扫帚傀儡：挥扫玩家和地面植物，制造位移。
- 磨壳兽：缓慢推进并占据大面积安全区。

本关主要陷阱：

- 齿轮轨道：先亮起轨道，再有齿轮沿固定路线滚过。
- 风车扇叶：周期性改变弹道和角色移动。
- 落谷口：地面出现颗粒阴影后倾泻谷物，形成临时减速堆。

Boss：**巨型收割傀儡**。

---

### 5.4 第四关：冬·静月根庭

**体验定位**：综合考验构筑、走位和延迟判断，使用“少而危险”的敌人与“多而可读”的弹幕。  
**视觉**：白根、深蓝冰面、淡紫月光、冻结水渠和倒悬庭院。  
**音乐**：空灵钟声、低声合唱与缓慢心跳，Boss 阶段逐步加入前三关的乐器。  
**场地规则**：冰冻土地无法正常播种，先用攻击、火焰或晨露圈破冰；被净化后会短暂进入高肥力状态。

敌人：

- 霜芽兽：跳跃落地后向四周产生冰裂线。
- 月铃侍：发射一组暂停后继续移动的延迟弹。
- 镜兔：短暂复制最近一次友方弹体，但复制品为敌对弹。
- 白藤守卫：从房间边缘生成封路根墙。
- 雪铲傀儡：铲起冰块形成移动掩体。
- 忆孢体：分别使用春、夏、秋敌人的一种简化招式。

本关主要陷阱：

- 冰裂：裂纹分两次扩张，第二次才造成伤害。
- 月镜柱：提前显示折射方向，再改变经过弹体的路线。
- 倒生根印：玩家脚下留下印记，1.2 秒后从记录位置长出根刺。

Boss：**倒生的月根之心**。

## 6. 难度成长

### 6.1 数值基准

| 指标 | 第一关 | 第二关 | 第三关 | 第四关 |
|---|---:|---:|---:|---:|
| 房间威胁预算 | 5–8 | 8–12 | 11–16 | 14–20 |
| 普通敌人生命倍率 | 1.00 | 1.12 | 1.25 | 1.38 |
| 精英出现率 | 8% | 12% | 18% | 25% |
| 普通房敌弹软上限 | 16 | 22 | 28 | 34 |
| Boss 敌弹软上限 | 36 | 44 | 52 | 60 |
| 常见弹速 | 85–115 | 95–130 | 105–145 | 110–155 |
| 强攻击前摇 | 0.8–1.2 秒 | 0.7–1.1 秒 | 0.6–1.0 秒 | 0.55–0.95 秒 |

“敌弹软上限”不是达到数量后突然删除子弹，而是攻击调度器延迟下一名远程敌人的攻击，避免多个敌人在同一帧同时开火。

### 6.2 四级难度语言

1. **第一关：介绍**  
   一次只强调一种威胁，例如追踪、直射或冲撞。
2. **第二关：组合**  
   远程弹幕与高速近战共同出现，开始要求改变站位。
3. **第三关：扭曲**  
   风向、反弹和强制位移会改变原本熟悉的弹道。
4. **第四关：考试**  
   延迟弹、封路和前三关招式的简化变体组合出现。

### 6.3 难度设计规则

- 一个普通敌人最多承担两种职责。
- 同时最多存在两个“高压招式”，其余敌人进入移动或准备状态。
- 弹幕增加时必须保留可识别的安全缺口，不用完全随机角度封死玩家。
- 陷阱和弹幕同时启动时，至少留出一条宽度不低于角色碰撞体 2.5 倍的安全通道。
- 普通敌人的跨关生命增长控制在 40% 左右，主要难度来自组合而非耐久。
- 同一种敌人进入后续关卡时只能增加一个明显变体，例如弹体分裂或死亡留区，不能同时提高全部属性。

### 6.4 三档可选难度

玩家在开始新游戏前选择难度。难度一旦进入单局便不能修改，继续游戏时沿用存档中的难度。

| 调整项 | 简单 | 普通 | 困难 |
|---|---:|---:|---:|
| 普通房威胁预算 | ×0.75 | ×1.00 | ×1.30 |
| 同时存活小怪数量 | 基准减少 1–2 只，最低 2 只 | 按房间配置 | 基准增加 1–3 只，但不突破可读性上限 |
| 小怪攻击力 | ×0.75 | ×1.00 | ×1.35 |
| 小怪生命 | ×0.90 | ×1.00 | ×1.15 |
| 小怪攻击间隔 | ×1.15 | ×1.00 | ×0.88 |
| 普通房敌弹软上限 | ×0.80 | ×1.00 | ×1.25 |
| 精英出现率 | 基准 −5 个百分点 | 按关卡基准 | 基准 +8 个百分点 |
| Boss 攻击力 | ×0.80 | ×1.00 | ×1.25 |
| Boss 第一血条生命 | ×0.90 | ×1.00 | ×1.15 |
| Boss 额外形态 | 无 | 无 | 有，第二条独立血条 |
| 积分倍率 | ×0.80 | ×1.00 | ×1.50 |

难度调整顺序为：

1. 先调整房间威胁预算和敌人数量。
2. 再调整攻击力、攻击间隔和弹幕密度。
3. 最后才少量调整生命，避免困难模式变成单纯的高血量消耗战。

简单模式额外规则：

- 每关入口恢复 1 点生命。
- 强攻击预警延长 0.2 秒。
- 同时最多出现 1 个高压招式。
- Boss 不减少反击窗口，也不删除核心机制。

困难模式额外规则：

- 同时最多出现 3 个高压招式，但仍必须保留安全通路。
- 精英敌人可能带有一个明确词缀，但不能同时获得多个词缀。
- Boss 增加攻击方式，并在第一条血量耗尽后进入第二形态。
- 困难模式提高的是组合和节奏压力，不允许取消预警、制造必伤局面或让弹幕与背景无法区分。

## 7. 弹幕设计语言

敌方弹幕分为六种基础语法，按关卡逐步解锁：

| 弹幕 | 首次出现 | 用途 | 必须保留的反制 |
|---|---|---|---|
| 瞄准直射 | 第一关 | 迫使玩家离开原位置 | 射击前显示方向线或身体朝向 |
| 扇形弹 | 第一关 Boss | 压缩正面空间 | 扇形两侧或弹间留出通道 |
| 缺口环形弹 | 第二关 | 要求观察安全角 | 缺口在发射前以花瓣方向提示 |
| 反弹/折射弹 | 第三关 | 改变熟悉路线 | 墙面或镜柱先显示反射方向 |
| 旋转/螺旋弹 | 第三关 Boss | 持续走位压力 | 转速稳定，不突然反转 |
| 延迟回声弹 | 第四关 | 记忆与节奏判断 | 暂停时保持清晰轮廓并显示恢复倒计时 |

视觉规则：

- 友方弹为青绿核心和圆润轨迹；敌弹为橙红、紫红核心和尖锐轮廓。
- 不能被近战打回的“重型弹”使用双层黑边。
- 即将恢复运动的延迟弹先闪烁两次。
- 弹幕和场地陷阱不能使用完全相同的颜色、轮廓与预警音。

## 8. 陷阱通用规则

- 所有伤害陷阱至少有 0.75 秒的视觉前摇和独立音效。
- 陷阱默认同时伤害玩家和敌人；对普通敌人的伤害约为对玩家等效伤害的 1.5 倍。
- 每个普通房最多启用两类陷阱。
- 玩家出生点周围 64 px 内不会立即生成活动陷阱。
- 房间清除后陷阱停用，避免拾取奖励时受伤。
- 敌人可以被推动、引诱或击退到陷阱中，使陷阱也是玩家的战术资源。
- 精英房可以使用“陷阱强化”规则，但必须在房门和地图图标上提前提示。

## 9. 四个 Boss 设计

### 9.1 灯笼南瓜王

**考验内容**：基础走位、利用植物、观察灯光前摇。

阶段一，100%–65%：

- 五枚瓜籽扇形弹。
- 王冠落地：地面三次收缩预警后跳砸。
- 两条缓慢生长的藤蔓改变路线。

阶段二，65%–30%：

- 房间熄灯，Boss 体内的橙光负责提示攻击方向。
- 扇形弹增加到七枚，但攻击后有更长恢复窗口。
- 跳砸会留下肥沃土地，提供反击资源。

阶段三，30%–0%：

- 裂成三个共享生命的瓜瓣。
- 三个瓜瓣依次攻击，不同时释放完整弹幕。
- 成熟植物的范围收割可以同时命中多个瓜瓣。

击败奖励：解锁南瓜系种子，并从三个“春季祝福”中选择一个。

### 9.2 失控蜂箱母机

**考验内容**：持续移动、处理召唤物、寻找激光安全扇区。

阶段一，100%–70%：

- 召唤侦蜂，母机发射弧形蜂针。
- 地面出现蜂蜜格，减速玩家但也能黏住小型敌人。

阶段二，70%–35%：

- 三面蜂蜡护盾轮流开启，只能从缺口攻击核心。
- 聚光激光绕场扫射，蜂巢柱可以暂时挡住光束，但会被烧毁。

阶段三，35%–0%：

- 护盾熔化，核心暴露并提高移动速度。
- 旋转花粉环与激光交替出现，始终保留两个安全扇区。
- 母机过热后坠地 3 秒，是主要输出窗口。

净化夏季根结后：激光转速降低 15%，过热倒地时间延长 0.5 秒。

击败奖励：解锁蜂蜡或花粉种子，并从三个“夏季祝福”中选择一个。

### 9.3 巨型收割傀儡

**考验内容**：近身时机、强制位移、使用场地让 Boss 失衡。

阶段一，100%–70%：

- 大范围镰刀横扫，先以地面弧线标记范围。
- 谷粒炮弹落地后分裂为十字弹。

阶段二，70%–40%：

- 房间传送带启动，周期性改变移动方向。
- Boss 投掷回旋镰，去程和回程都造成伤害。
- 玩家可引导镰刀击中边缘齿轮，使 Boss 卡顿。

阶段三，40%–0%：

- 四条齿轮轨道依次启动，而不是同时封场。
- Boss 横扫会切开成熟植物，使其立即向两侧爆发。
- 每完成两轮组合攻击，Boss 会因过载跪地 2.5 秒。

净化秋季根结后：每轮有一条传送带停止，齿轮轨道预警延长 0.2 秒。

击败奖励：解锁麦穗或齿轮种子，并从三个“秋季祝福”中选择一个。

### 9.4 倒生的月根之心

**考验内容**：综合运用整局构筑、识别延迟弹、净化腐化地。

阶段一，100%–75%：

- 使用冰裂、月根突刺和带缺口的低速环形弹。
- Boss 本体倒悬，弱点沿根须在三个位置间移动。

阶段二，75%–45%：

- 每轮只抽取前三个 Boss 的一个简化招式作为“季节回声”。
- 场地依次短暂变为春湿、夏热、秋风状态，顺序固定并提前显示图标。

阶段三，45%–15%：

- 发射静止的种子弹；1.2 秒后从外向内倒放轨迹。
- 腐化地块会生出护根，玩家需用成熟植物或晨露圈净化。

终幕，15%–0%：

- 场地暂时安静，前三关获得的三个季节祝福化为可站立的安全花圃。
- Boss 进行两轮固定但密集的最终弹幕，完成后长期暴露核心。
- 终幕不再随机追加招式，胜负取决于读懂规律而不是运气。

净化冬季根结后：延迟弹恢复运动前增加第三次闪烁，安全花圃面积提高 20%。

击败奖励：完成本局，解锁新角色、剧情和更高难度规则。

### 9.5 Boss 共通标准

- 每个 Boss 由 3 个主要阶段组成，每次转阶段只加入一个核心规则。
- 每 12–18 秒至少出现一次 2–3 秒的明确反击窗口。
- Boss 战目标时长为 2.5–4 分钟，超过 5 分钟优先检查无效等待和血量。
- 阶段转换期间不造成伤害，用动画、场景和音乐清楚说明新规则。
- Boss 招式不能和背景装饰争夺可读性。

### 9.6 困难模式第二形态

困难模式下，每个 Boss 拥有两条独立血条：

- **第一血条**：使用普通模式的完整阶段，并加入一项困难专属攻击。
- **第二血条**：第一血条耗尽后触发第二形态，生命值为第一血条的 60%。
- 第二血条使用不同颜色、罗马数字“Ⅱ”和独立名称，不能让玩家误以为第一条血量只是重新填满。
- 转形态时立即清除场上敌弹和活动陷阱，播放 2.5–3 秒不可伤害演出。
- 演出结束前显示新血条和新场地规则，玩家获得重新站位的机会。
- 第二形态至少增加两种新攻击，其中一种改变场地，另一种改变弹幕组合。
- 第二形态不能只提高弹速、伤害和攻击频率。
- 困难 Boss 总战斗目标时长为 3.5–5.5 分钟；超过 6 分钟优先减少生命和无敌时间。

困难模式各 Boss 的专属变化：

| Boss | 第一血条新增攻击 | 第二形态 | 第二形态核心攻击 |
|---|---|---|---|
| 灯笼南瓜王 | 投出会反弹一次并分裂的灯籽 | **裂灯根王** | 四象限根须扫场；灯籽环在爆炸前留下旋转安全缺口 |
| 失控蜂箱母机 | 两座镜柱同时进行交叉预瞄 | **蜂后过载核心** | 六边形激光网依次点亮；蜡墙把场地暂时切成两条走廊 |
| 巨型收割傀儡 | 冲锋后留下短时运转的刀轨 | **脱壳收割机** | 传送带周期反向；外圈齿轮与中央冲击波交替压缩空间 |
| 倒生的月根之心 | 延迟弹生成一次镜像回声 | **月根倒悬真心** | 花瓣安全区顺序收缩；镜面复制上一轮弹幕但保留更宽缺口 |

困难模式在 Boss 房退出或崩溃后继续游戏时，Boss 战从第一血条开始重置，玩家也恢复到进入 Boss 房前的房间快照，防止通过反复退出保存阶段进度。

首次在普通难度击败某个 Boss 后，营地训练区解锁该 Boss 的“温室回忆战”。回忆战可以单独练习普通阶段；首次见过困难第二形态后，也可在回忆战练习第二形态。回忆战不提供正式积分和资源，只记录练习用时与受伤次数，确保高成本 Boss 内容不会只服务少数困难玩家。

## 10. 新武器体系

### 10.1 装备规则

- 玩家同时持有 **1 把主武器 + 1 种主种子**，保留现有翻滚、收割和角色主动技能。
- 营地可以从已解锁武器中选择起始武器。
- 宝藏房、精英奖励和商店可能出现武器架，允许查看完整属性后替换。
- 基础武器不使用通用弹药，各自通过攻击间隔、连段、热量或回收时间限制输出。
- 通用遗物在换武器后仍然有效；武器专属改造会自动转换为新武器的同级改造，避免玩家因换武器损失投入。
- 每关最多出现一次工具改造台，从三个行为改造中选择一个；单把武器最多安装三个改造。

### 10.2 武器清单

| 武器 | 类型与攻击方式 | 优势 | 弱点 | 与种植的联系 |
|---|---|---|---|---|
| 芽枝杖 | 连续发射直线芽弹 | 稳定、易瞄准、适合新手 | 范围控制一般 | 命中成熟植物后弹向最近敌人 |
| 月牙镰 | 110°近战挥砍，三段连击 | 清弹、范围近战、收割效率高 | 必须接近敌人，第三击后有硬直 | 第三击可触发附近成熟植物 |
| 日棱喷壶 | 按住发射持续激光，积累热量 | 穿透、精准、持续伤害高 | 转向速度降低，过热后停机 | 光束经过植物会催熟，成熟植物可折射光束 |
| 蒲籽风铳 | 一次发射 5 枚扇形种弹 | 近距离爆发和大范围播种 | 远距离伤害分散 | 多枚命中同一地块可快速形成苗印 |
| 枝杈弹弓 | 蓄力发射高速大种弹 | 单发高伤、穿透、击退强 | 蓄力时移动略慢 | 满蓄力命中植物会立即推进一个生长阶段 |
| 回旋园剪 | 投出双刃，去程与回程均攻击 | 控场、两次命中、可切割弹幕 | 刀刃未返回时无法再次攻击 | 回程经过成熟植物会带回一次收割能量 |
| 雷藤叉 | 中距离电弧，向邻近目标跳跃 | 群体清理、湿地表现强 | 单体伤害偏低，需要目标链 | 电流会沿相连湿地和植物传导 |
| 葫芦轰果炮 | 抛物线重弹，落地范围爆炸 | 高范围伤害、破甲、炸开障碍 | 射速慢，近身有盲区 | 爆炸会立刻收割植物，并继承部分收割效果 |

### 10.3 三类重点新武器

#### 月牙镰：近战武器

基础节奏：

1. 第一击为快速横斩。
2. 第二击为反向横斩。
3. 第三击为重劈，伤害和击退更高。

精准挥砍窗口为攻击开始后的 0.12 秒，可弹回小型敌弹；大型双描边弹、激光和地面伤害无法弹回。这样近战武器可以主动处理弹幕，但不能站桩无敌。

改造方向：

- **丰收刃**：第三击自动收割小范围内的成熟植物。
- **牵藤钩**：第二击把轻型敌人拉近，把玩家拉向大型敌人。
- **月弧**：精准弹回敌弹后发射一枚短程月牙波。

#### 日棱喷壶：激光武器

基础节奏：

- 按住攻击持续照射，约 4 秒达到过热。
- 停止攻击后热量快速下降；完全过热会强制停机 1.6 秒。
- 光束可以穿透普通敌人，但转向速度低于鼠标移动速度，要求提前扫线。

改造方向：

- **三棱芽镜**：光束经过成熟植物后分裂成两道弱光束。
- **温室光谱**：光束催熟速度提高，但直接伤害降低。
- **灼芯**：高热量时伤害提高，并给敌人附加短暂燃烧。

#### 蒲籽风铳：扇形弹幕武器

基础节奏：

- 一次发射 5 枚、总角度约 60° 的种弹。
- 单枚伤害较低，近距离让多枚命中同一目标时爆发很高。
- 连续攻击三次后需要短暂摇匀种仓，形成明显的进攻节拍。

改造方向：

- **满天播**：增加到 7 枚，扇形更宽，单枚伤害下降。
- **束口环**：扇形收窄到 28°，适合中距离集中输出。
- **墙根反芽**：种弹碰墙反弹一次，反弹后优先飞向附近敌人。

### 10.4 武器平衡原则

- 所有起始武器都能不依赖特定遗物完成第一关。
- 武器差异首先体现为距离、瞄准、移动和资源节奏，不先用基础伤害区分强弱。
- 近战高风险换取清弹与高爆发；激光用转向和热量限制持续伤害；扇形武器用距离和装填限制爆发。
- 每把武器至少有一个与植物交互的机制，以及一个不能靠堆伤害消除的弱点。
- 同类增伤优先加算，行为改造不无限乘算。

## 11. 局内构筑与跨关奖励

一局构筑由六层组成：

1. 主武器：决定基础攻击操作。
2. 主种子：决定落地、附着和收割方式。
3. 武器改造：改变武器行为。
4. 遗物：建立跨系统协同。
5. 季节祝福：击败 Boss 后获得的强力方向选择。
6. 月根网络：决定跨房间传播、路线变化和 Boss 场地。

### 11.1 构筑标签与成型提示

主种子、武器、遗物、土地配方和根忆节点统一使用以下标签：

`湿润 / 燃烧 / 孢子 / 扎根 / 月照 / 腐化 / 收割 / 附着`

设计规则：

- 每件资源重点支持 1–2 个标签，避免一件遗物同时服务所有构筑。
- 纯数值属性不能单独构成最高稀有度奖励。
- 稀有奖励优先改变规则，例如“收割触发两次”“敌弹可被植物吸收”“附着效果转移到附近目标”。
- 组合说明直接展示触发条件、影响对象和代价，不隐藏核心公式。
- 玩家形成两项稳定联动后，HUD 显示构筑名称和主要循环。
- 奖励三选一至少包含一个当前标签相关项、一个通用生存项和一个转型项，降低完全无用选择的概率。
- 每关温室允许封存一个当前不需要的奖励，使其在下一关商店或宝藏房再次出现一次。

构筑成型阶段：

| 阶段 | 目标 |
|---|---|
| 前 3 个战斗房 | 确定主武器、主种子和第一个标签 |
| 第一关 Boss 前 | 形成至少一组“种子 + 土地/武器”联动 |
| 第二关 Boss 前 | 形成一个三节点生态配方或明确选择零留根路线 |
| 第三、第四关 | 用季节祝福放大现有规则，而不是不断添加新按钮 |

### 11.2 收割、留根与零留根路线

清房后选择：

- **立即收割**：得到当前植物的完整收割效果、资源和恢复，适合速通与生存压力大的构筑。
- **留下根系**：放弃该植物的即时收割收益，将房间变为根忆节点，换取跨房间和 Boss 收益。

零留根路线必须可通关，并通过更高即时资源、短战斗时间和专属“荒行”结算获得独立价值。留根路线则以生态配方、路线控制和 Boss 场地援助见长。两者不是正确与错误，而是不同构筑方向。

为防止每次清房都弹出窗口打断节奏：

- 房间只存在一个成熟候选时，玩家长按收割键立即收割，长按地图键留下根系。
- 存在多个候选时才打开简短选择轮盘。
- 玩家可在设置中指定默认行为，并在 3 秒内撤销一次。

### 11.3 季节继承与 Boss 读取

进入 Boss 房时，系统统计本关节点，而不是简单给 Boss 统一减益：

| 网络结果 | Boss 房变化 |
|---|---|
| 湿润节点占优 | 出现可催熟的水渠；Boss 的电或蒸汽招式也能利用水渠 |
| 燃烧节点占优 | 玩家获得一次高爆发花圃；部分安全区会短时灼热 |
| 扎根节点占优 | 生成掩体和稳定区域；可移动空间略微缩小 |
| 月照节点占优 | 出现镜花和更高奖励倍率；Boss 增加一项变异攻击 |
| 腐化节点占优 | Boss 获得强化，积分倍率上升并掉落额外稀有奖励 |
| 零留根 | 场地最干净、Boss 无额外强化；玩家获得“荒行”结算奖励 |

每个 Boss 最多读取两个占优标签，避免场地规则过多。

击败 Boss 后，玩家从本关网络中选择一个节点压缩为“季种印记”带入下一关。印记只保留标签与一次性触发，不直接复制上一关地形，保证换季后仍有全新感受。

### 11.4 奖励节奏

推荐奖励节奏：

| 时机 | 奖励 |
|---|---|
| 普通房 | 月露、种荚、小概率心莓 |
| 每清除 3 个战斗房 | 芽变三选一 |
| 精英房 | 1 个遗物 |
| 温室房 | 种子升级或土地配方 |
| 宝藏房 | 武器、稀有遗物或季叶 |
| 工具改造台 | 当前武器三个改造选一个 |
| Boss | 季节祝福三选一、恢复 2 点生命、补充 1 个种荚 |

季节祝福示例：

- **春雨留根**：每个房间第一株植物立刻进入半熟阶段。
- **盛夏折光**：友方弹体穿过日照地后分裂一次。
- **秋风归仓**：回收型攻击返回时恢复少量翻滚冷却。
- **冬土藏芽**：受到伤害时冻结周围敌弹 0.5 秒，每房间一次。

## 12. 关卡过渡

击败 Boss 后，Boss 房变为安全房：

1. 弹幕和陷阱全部清除。
2. 出现季节祝福三选一。
3. 玩家完成补给和拾取。
4. 房间中央长出通往下一关的“季门”。
5. 进入季门后播放 4–6 秒短过渡，场景色板、环境声和角色脚下材质立即改变。
6. 玩家从本关月根网络中选择一个节点压缩为季种印记，其余网络化为结算画面中的根系图。

每次过渡必须在隐藏 UI 的情况下也能让玩家在 3 秒内识别已经进入新关卡。区别至少来自：

- 主色板；
- 地面和墙体材质；
- 环境动态；
- 音乐乐器；
- 第一间安全房展示的新场地规则。

## 13. 内容规模建议

### 13.1 完整目标

- 4 个完整区域，4 个独立 Boss。
- 每区 10–12 个战斗房骨架，每个骨架至少 3 套敌人配置。
- 18–22 种基础敌人；后期关卡允许使用少量变体，但不直接换色复用。
- 8 把主武器，每把 3 个改造方向。
- 8 种主种子、40 个遗物、12 个季节祝福。
- 12–16 个生态配方、8 种统一构筑标签。
- 每区 3 类常规陷阱、1 类精英房特殊陷阱。
- 商店、温室、休息、事件、宝藏、隐藏房的完整流程。

### 13.2 后续开发时的推荐验证顺序

本节只是确定未来验证范围，不代表本轮开始开发。

1. 先制作春季 6–8 房间垂直切片，验证地图生成、探索、返回、Boss 发现和安全存档。
2. 只加入芽枝杖、月牙镰、日棱喷壶三把操作差异最大的武器。
3. 使用 4 种种子、3 种土地、12 个遗物和 4 个生态配方验证构筑标签。
4. 重点观察玩家是否会主动在“立即收割”和“留下根系”之间犹豫，而不是机械选择同一项。
5. 验证网络是否真正改变相邻房间、路线和 Boss；如果只表现为被动加成，先重做系统。
6. 春季切片通过验收后再制作夏季，验证季种印记和换季后规则重建。
7. 第二关通过后再扩充第三、第四关、困难第二形态和完整内容池。

### 13.3 春季垂直切片范围

垂直切片严格限制为：

- 1 名角色。
- 3 把武器。
- 4 种主种子。
- 湿润、肥沃、月照 3 种土地，腐化只作为事件状态。
- 4 种普通敌人、1 种精英变体。
- 每局抽取 6–8 个普通、精英或事件探索房，另有 1 个商店、1 个温室和 1 个 Boss 房，共 9–11 个房间。
- 12 个遗物，其中至少 8 个改变行为或资源循环。
- 4 个生态配方。
- 1 种主天气“小雨”和 1 种根系风险“腐化回流”。
- 普通难度；简单和困难只保留参数入口，不制作困难 Boss 第二形态。
- 自动存档、继续游戏和基础结算；排行榜先记录本地数据，不制作复杂展示。

垂直切片暂不要求：

- 四季完整美术和全部敌人。
- 40 个遗物和 20 个事件。
- 困难 Boss 第二形态。
- 在线排行榜、每日挑战和复杂营地经营。
- 大量剧情分支与全语音。

只有当种植率、留根率、生态配方触发率和 Boss 网络利用率通过第 14 节标准，才进入横向内容扩充。

## 14. 体验验收标准

满足以下条件后，扩展方向才算成立：

- 新玩家能在第一次进入地图后的 3 个房间内理解门、支路和 Boss 搜索方式。
- 玩家通常能在 6–10 分钟内找到本关 Boss，不会因随机地图长时间迷路。
- 同一关连续游玩 3 次，至少出现两条明显不同的行进路线和奖励选择。
- 四关在关闭 UI 后仍能仅凭画面和声音快速区分。
- 四个 Boss 分别考验基础走位、持续移动、强制位移和延迟判断，不产生明显换皮感。
- 后期难度上升时，测试者仍能准确描述自己为何受伤。
- 至少 70% 的遗物或武器改造会改变战斗行为，而不只是提高伤害数值。
- 近战、激光、扇形弹幕和基础直射四类武器都能独立完成完整单局。
- 普通房平均战斗时间不超过 65 秒，返回已清房间不超过 8 秒。
- Boss 战稳定控制在 2.5–4 分钟，没有依靠超高生命拖延时长。
- 至少 80% 的测试者能准确说明“立即收割”和“留下根系”各自带来的收益与代价。
- 连续三局中，玩家的平均留根率应处于 25%–75%；若长期低于或高于该区间，说明其中一个选项已成为伪选择。
- 玩家通常能在第 4–6 个房间前主动完成第一个三节点生态配方，并能在选择奖励时说出自己正在追求的标签。
- 根系网络每关至少明显改变一个相邻房间、一项路线决策和 Boss 的一种攻击或场地反馈。
- “零留根”与“网络成型”两条路线都能完成普通难度；前者依赖即时资源和操作，后者依赖规划并承担 Boss 继承风险。
- 玩家在进入新房间前能依据预报说出即将发生的天气，并至少一次因天气改变路线、播种或契约选择。
- 完全不播种仍允许通关，但同等水平下资源效率和构筑上限明显低于主动利用种植的玩家，不以硬门槛强迫使用系统。

## 15. 单局存档与继续游玩

### 15.1 存档范围

游戏只保留一个“进行中单局”自动存档。永久解锁、设置和积分榜属于独立档案，不会被开始新游戏覆盖。

自动存档必须包含：

- 存档版本号和校验信息；
- 单局种子、难度、角色和累计有效游玩时间；
- 当前关卡、当前房间、房间地图和门连接关系；
- 已发现、已清除、已领取和已净化的房间状态；
- 根忆节点、根线、生态配方、天气序列和季种印记；
- 当前生命、武器、种子、遗物、季节祝福、货币和消耗品；
- 随机数状态和各奖励池已抽取结果；
- 当前房间入口快照。
- 安全继续次数、战斗中断次数和本局是否符合挑战榜资格。

### 15.2 自动存档时机

在以下安全节点写入存档：

1. 创建新单局后。
2. 进入一个新房间、门在身后关闭前。
3. 战斗房清除、掉落结果确定后。
4. 选择奖励、购买物品或完成事件后。
5. 击败 Boss、进入下一关入口房后。
6. 返回主菜单或正常退出游戏时。

不在弹幕飞行、伤害结算或 Boss 转阶段的任意帧直接存档。

### 15.3 继续规则

- 从非战斗房退出：继续时恢复当前房间和完整状态。
- 从未清除战斗房退出或崩溃：继续时回到该房间入口，敌人重新生成，玩家状态回滚到进入房间时。
- 从 Boss 战退出或崩溃：继续时回到 Boss 房入口，Boss 从第一血条开始，玩家回滚至入场快照。
- 已经确定的地图、商店、宝箱和奖励结果不能因重新打开游戏而刷新。
- 根忆节点、天气和生态配方不能因重新打开游戏而改变。
- 暂停、加载、切到后台和游戏关闭期间不累计游玩时间。
- 死亡或击败最终 Boss 后，进行中存档立即作废并生成结算记录。

从已清除房间、入口房、商店、温室和休息房正常退出属于安全继续，不影响排名。未清除战斗房或 Boss 房发生退出时增加一次“战斗中断”：

- 每关第一次战斗中断仅记录，不扣分，用于容纳偶发崩溃。
- 同一关第二次及以后中断，记录标记为“回溯局”。
- 回溯局仍可进入本地普通榜，但不进入每日农时、未来在线榜和速通榜。
- 主动选择“返回主菜单”时提示当前房间是否安全，减少误操作。

存档写入采用“临时文件写完后原子替换正式文件”的方式，并保留一个上一版本备份，降低异常退出导致坏档的概率。

## 16. 积分结算与排行榜

### 16.1 记录时机

以下两种结果必须进入正式积分榜：

1. 玩家死亡，记录死亡所在关卡和此前已经通过的关卡。
2. 玩家击败第四关最终 Boss，记录为完整通关。

主动覆盖旧存档或主动放弃只进入历史记录，不进入正式排名，避免用大量低质量中断记录污染榜单。

### 16.2 单局记录字段

每条结算记录保存：

- 最终排名与总积分；
- 结果：死亡或完整通关；
- 难度；
- 通过关卡数、死亡关卡和击败 Boss 数；
- 每关获得积分与每关有效游玩时间；
- 总有效游玩时间；
- 清除普通房、精英房和隐藏房数量；
- 角色、最终武器和三个主要遗物；
- 单局种子、完成日期和记录版本。

### 16.3 基础积分

积分只在内容第一次完成时结算，重复进入已清除房间不加分。每关只有最先清除的 5 个普通战斗房提供基础房间积分，后续普通房只提供构筑和资源，避免积分最优解固定为清空全图。

| 行为 | 第一关 | 第二关 | 第三关 | 第四关 |
|---|---:|---:|---:|---:|
| 清除普通战斗房 | 100 | 120 | 140 | 160 |
| 清除精英房 | 400 | 500 | 650 | 800 |
| 净化季节根结 | 250 | 350 | 450 | 600 |
| 击败区域 Boss | 1,500 | 2,500 | 3,500 | 5,500 |

附加积分：

- 发现隐藏房：200 分，每关最多一次。
- 无伤清除战斗房：基础房间积分的 25%，每房只结算一次。
- 完整通关奖励：3,000 分。
- 困难模式击败一个第二形态：额外获得该 Boss 基础积分的 30%。
- 每完成一个三节点生态配方：250 分，每关最多结算两个不同配方。
- 零留根路线击败 Boss：该 Boss 基础积分额外增加 10%。

进入未清除战斗房前，玩家可以自愿选择一个“房间契约”：

| 契约 | 效果 | 挑战倍率 |
|---|---|---:|
| 虫潮 | 增加一组普通敌人 | +5% |
| 旱季 | 本房植物成长速度降低 25% | +8% |
| 禁翻 | 翻滚冷却延长 50% | +10% |
| 腐土 | 两块土地初始腐化 | +10% |
| 精英授粉 | 一名敌人升级为精英 | +15% |

每个房间最多选择一个契约，倍率只作用于该房间的基础积分和无伤奖励。契约在进门前确定，继续游戏不能刷新。

生态风险倍率：

- 每个仍然连接 Boss 的腐化节点提供 +5%，每关最多 +20%。
- 月照网络为 Boss 增加变异攻击时提供 +10%。
- 生态风险倍率只作用于本关 Boss 积分，不作用于普通房。

积分计算：

```text
房间契约奖励 = 向下取整（该房基础积分与无伤奖励 × 契约加成百分比）
Boss 生态奖励 = 向下取整（Boss 基础积分 × 生态风险加成百分比）
难度前总分 = 基础积分 + 附加积分 + 房间契约奖励 + Boss 生态奖励
最终积分 = 向下取整（难度前总分 × 难度倍率）
```

难度倍率为简单 0.80、普通 1.00、困难 1.50。

游玩时间默认不直接扣分，避免惩罚探索支路的玩家。总积分相同时，依次比较：

1. 通过关卡数更多；
2. 击败 Boss 数更多；
3. 总有效游玩时间更短；
4. 记录完成时间更早。

### 16.4 排行榜界面

首版使用本地排行榜，分为：

- 综合；
- 简单；
- 普通；
- 困难；
- 生态挑战；
- 完整通关速通。

每个分页保存前 100 条记录。综合榜按难度倍率后的总积分排序；生态挑战榜优先比较契约和生态风险积分；速通榜只包含无“回溯局”标记的完整通关记录，并按有效游玩时间升序排列。

列表至少显示：排名、结果、难度、通过关卡、总积分、总时间、角色、继续次数、战斗中断和日期。选中记录后展开每关积分、每关时间、最终构筑、生态配方、契约和单局种子。

在线排行榜需要服务器校验、版本隔离和反作弊，不纳入首版开发范围。

## 17. 新增系统验收标准

- 正常退出、强制关闭和崩溃后，均能通过“继续游戏”回到正确关卡。
- 未清除房间重新进入时不会保留敌人残血，也不会重复领取已经确定的奖励。
- 继续十次后，地图、商店和宝箱内容保持一致，不能通过重开刷新。
- 暂停、后台、加载和离线时间不会进入排行榜计时。
- 死亡和完整通关都会生成且只生成一条正式记录。
- 简单、普通、困难三档能明显感受到敌人数量和攻击力差异。
- 困难 Boss 第二血条有清楚的转形态演出、独立名称和至少两种新攻击。
- 困难 Boss 第二形态仍保留可识别安全区和反击窗口。
- 同一条记录在积分榜、结算界面和存档历史中显示的积分与时间完全一致。
- 损坏正式存档时可以回退到上一个安全节点备份，不删除永久解锁与排行榜。
- 存档前后的根忆节点、连接、天气、生态配方和季种印记逐项一致。
- 同关第二次战斗中断会稳定标记为“回溯局”，且不会进入生态挑战榜、未来在线榜和速通榜。
- 每关只有最先清除的 5 个普通战斗房提供基础积分，继续游戏与往返房间不会重复计分。
- 房间契约一旦确定就写入房间状态，退出并继续不能刷新契约、敌人配置或挑战倍率。
- 零留根路线与网络成型路线的普通难度通关率差距控制在 15 个百分点以内。

## 18. 更新后的最终建议

本次扩展采用以下默认结论：

1. 完整单局为四关四 Boss，而不是无限重复同一套房间。
2. 每关生成 12–15 个房间，玩家自由探索其中 7–10 个。
3. Boss 需要通过探索发现，但不使用强制钥匙阻挡。
4. “月根网络”是核心差异：玩家在收割与留根之间选择，让房间跨区域连接，并把整张地图培育成构筑。
5. 后期难度以敌人组合、陷阱、弹幕数量和弹幕规则为主，生命增长为辅。
6. 首批重点新增武器为月牙镰、日棱喷壶和蒲籽风铳，分别代表近战、激光和扇形弹幕。
7. 四关分别使用湿润、灼热、风向和冻结/延迟作为主场地机制。
8. 每个 Boss 拥有独立的战斗课题和场地互动，不复用同一套阶段模板。
9. 主菜单支持开始新游戏和继续游戏，自动存档以房间入口快照为最小安全单位。
10. 死亡和击败最终 Boss 都生成正式积分记录，包含每关积分、每关时间和总时间。
11. 难度分为简单、普通、困难，难度在创建单局时确定并写入存档。
12. 困难模式 Boss 拥有额外攻击和第二形态独立血条，但不能依靠纯数值膨胀制造难度。
13. 普通房基础积分设每关 5 房上限，配合房间契约与生态风险奖励高质量挑战，避免全清成为唯一最优解。
14. 局外温室只承担图鉴、根忆陈列、练习和内容解锁，不加入实时种田、收菜或日常任务。
15. 开发先完成春季 6–8 房垂直切片；月根网络通过验收后，再扩充四季、美术内容与困难第二形态。
