# 《月根秘境》首版内容与数值草案

版本：平衡草案 v0.1  
说明：所有数值用于建立原型尺度，不是最终平衡结果。

| 项目 | 初始值 |
|---|---:|
| 玩家生命 | 6 点（3 颗心） |
| 玩家移动速度 | 100 设计像素/秒 |
| 翻滚距离 | 44 设计像素 |
| 翻滚冷却 | 1.1 秒 |
| 受伤无敌 | 0.8 秒 |
| 基础攻击伤害 | 10 |
| 基础攻击频率 | 2.5 次/秒 |
| 种荚上限 | 3 |
| 普通种荚恢复 | 平均每 2 个房间恢复 1 个 |

### 1.1 伤害基准

- 普通小怪目标击杀时间：0.8–2.0 秒。
- 坚韧小怪：2.5–4.0 秒。
- 精英：12–20 秒。
- 首区 Boss：未成型构筑约 4 分钟，正常构筑约 2.5–3 分钟。
- 单次普通受伤为 1 点；强预警招式可造成 2 点。

推荐伤害公式：

`最终伤害 = 基础伤害 × 加算伤害倍率 × 独立机制倍率 × 暴击倍率`

同类百分比优先加算，少量改变玩法的稀有遗物使用独立倍率，避免无限乘算失控。

## 3. 主工具

### 芽枝杖

均衡远程武器。发射直线芽弹，射程 190 px，伤害 10，频率 2.5/秒。

三条强化方向：

- 分杈：弹体数量增加，单发伤害下降。
- 蓄芽：按住蓄力，满蓄可穿透并立即推进植物一个阶段。
- 回春：命中成熟植物后弹向最近敌人。

### 后续工具池

| 工具 | 定位 | 核心差异 |
|---|---|---|
| 枝杈弹弓 | 中距离爆发 | 完美松弦可提高暴击与击退 |
| 月牙镰 | 近战范围 | 收割植物可重置部分攻击间隔 |
| 蜂针壶 | 持续射击 | 热量越高射速越快，过热后需浇水 |

## 8. 房间内容

### 8.1 原型 12 个骨架

- 3 个开阔教学房。
- 3 个中央障碍房。
- 2 个环形走廊房。
- 2 个分区土壤房。
- 1 个高腐化高奖励房。
- 1 个 Boss 房。

每个骨架至少配置 3 套敌人组合和 2 套土壤分布，形成最低 60 种有效变体。

### 8.2 房间奖励概率

| 奖励 | 基础概率 |
|---|---:|
| 月露 | 100% |
| 心莓 | 15%，低生命时最高提升至 35% |
| 种荚 | 22%，种荚为空时最高提升至 45% |
| 遗物选择 | 每 3 个普通战斗房保底 1 次 |
| 温室入口 | 每区域 1 次保底 |

动态补给只提高容错资源，不直接增加高稀有遗物概率。

## 9. 经济草案

| 项目 | 月露价格 |
|---|---:|
| 恢复 1 点生命 | 8 |
| 补充 1 个种荚 | 10 |
| 普通遗物 | 18–24 |
| 罕见遗物 | 32–40 |
| 重铸一次奖励 | 12，之后每次 +6 |
| 查看两个未探索房间情报 | 6 |

期望每区域自然获得 35–50 月露，使玩家通常能购买一个关键遗物，再在恢复、种荚或情报中选择一项。

## 10. 难度曲线

房间威胁值建议：

`房间威胁 = 基础区域值 + 已清房数 × 0.7 + 精英修正 + 路线风险修正`

不建议让敌人生命无限随时间增长。区域内主要增加敌人组合复杂度；跨区域时普通敌人生命可提升 20%–30%，同时引入新行为。

舒缓模式：敌人移动和弹速 ×0.85，攻击前摇 ×1.15；不修改掉落、剧情或成就。

## 11. 数据验证指标

原型测试重点记录：

- 每房耗时、受伤次数、种植次数、成熟率、主动收割率。
- 每个遗物的选择率、胜率与放弃原因。
- 玩家首次主动利用土地状态的时间。
- 首个协同组合形成的房间序号。
- Boss 各招式命中率与玩家识别描述。
- 失败后再次开局率，以及玩家自述的失败原因。

首轮目标区间：

| 指标 | 目标 |
|---|---:|
| 普通房平均耗时 | 45–65 秒 |
| 首区单房平均受伤 | 0.25–0.5 点 |
| 种下植物的成熟率 | 60%–80% |
| 成熟植物主动收割率 | 40%–65% |
| 首次形成协同 | 第 3–5 个房间 |
| 首次挑战 Boss 胜率 | 30%–45% |

数值超出范围时先调整前摇、移动路线和资源反馈，再考虑直接修改生命或伤害。
