# 《月根秘境》首版内容与数值草案

版本：平衡草案 v0.2

说明：所有数值用于建立原型尺度，不是最终平衡结果。

| 项目 | 初始值 |
|---|---:|
| 玩家生命 | 6 点（3 颗心） |
| 玩家移动速度 | 100 设计像素/秒 |

| 受伤无敌 | 0.8 秒 |
| 基础攻击伤害 | 10 |
| 基础攻击频率 | 2.5 次/秒 |
| 种荚上限 | 3 |
| 普通种荚恢复 | 平均每 2 个房间恢复 1 个 |

### 1.1 伤害基准

- 普通小怪目标击杀时间：0.8–2.0 秒。
- 坚韧小怪：2.5–4.0 秒。
- 精英：12–20 秒。
- 首区 Boss：未成型构筑约 4 分钟，正常构筑约 2.5–3 分钟。
- 单次普通受伤为 1 点；强预警招式可造成 2 点。

推荐伤害公式：

`最终伤害 = 基础伤害 × 加算伤害倍率 × 独立机制倍率 × 暴击倍率`

同类百分比优先加算，少量改变玩法的稀有遗物使用独立倍率，避免无限乘算失控。

## 3. 主工具

### 芽枝杖

均衡远程武器。发射直线芽弹，射程 190 px，伤害 10，频率 2.5/秒。主标签：附着、扎根。

三条强化方向：

- 分杈：弹体数量增加，单发伤害下降。
- 蓄芽：按住蓄力，满蓄可穿透并立即推进植物一个阶段。
- 回春：命中成熟植物后弹向最近敌人。

### 月牙镰

近战范围武器。基础斩击半径 42 px、伤害 18、频率 1.4/秒；斩击可清除轻型敌弹。命中成熟植物不会自动收割，按收割键才触发，避免误操作破坏留根计划。主标签：收割、扎根。

### 日棱喷壶

持续激光武器。0.25 秒预热后造成每秒 28 伤害，连续照射 2.5 秒进入过热；扫过湿润地时折射一次，照射植物可推进成长但加快过热。主标签：湿润、月照。

以上三把武器进入春季垂直切片，分别验证基础直射、近战和激光三种操作。扇形弹幕武器“蒲籽风铳”保留到切片通过后，避免首轮同时验证过多输入模型。

### 后续工具池

| 工具 | 定位 | 核心差异 |
|---|---|---|
| 枝杈弹弓 | 中距离爆发 | 完美松弦可提高暴击与击退 |
| 蜂针壶 | 持续射击 | 热量越高射速越快，过热后需浇水 |
| 蒲籽风铳 | 扇形弹幕 | 蓄力收束弹道，贴近植物可带走并传播种子 |

### 5.1 敌人预算规则

为每个敌人设置威胁点：基础近战 1 点、远程 1.5 点、冲撞 2 点、场地控制 2 点。首区房间从 4 点逐渐提升至 10 点，同类远程敌人默认不超过 3 个。

| 项目 | 数值草案 |

| 总生命 | 1,350 |

| 阶段三阈值 | 30% |

招式：

- **瓜籽扇**：0.9 秒前摇，5 枚扇形弹，阶段二增至 7 枚。
- **王冠落地**：地面显示三段收缩方框，1.2 秒后跳砸。

## 8. 房间内容

### 8.1 原型 12 个房间骨架池

- 3 个开阔教学房。
- 3 个中央障碍房。
- 2 个环形走廊房。
- 2 个分区土壤房。
- 1 个高腐化高奖励房。
- 1 个 Boss 房。

每个骨架至少配置 3 套敌人组合和 2 套土壤分布，形成最低 60 种有效变体。

垂直切片每局从骨架池抽取 6–8 个普通、精英或事件探索房，再连接 1 个商店、1 个温室和 1 个 Boss 房，共 9–11 个房间。不会在单局内用完全部骨架。

### 8.2 房间奖励概率

| 奖励 | 基础概率 |
|---|---:|
| 月露 | 100% |
| 心莓 | 15%，低生命时最高提升至 35% |
| 种荚 | 22%，种荚为空时最高提升至 45% |
| 遗物选择 | 每 3 个普通战斗房保底 1 次 |
| 温室入口 | 每区域 1 次保底 |

动态补给只提高容错资源，不直接增加高稀有遗物概率。

### 8.3 垂直切片生态配方

首轮只启用以下 4 个配方，全部使用统一标签，不引入隐藏条件：

| 配方 | 三节点标签 | 数值草案 |
|---|---|---|
| 雨后菌环 | 湿润 + 孢子 + 附着 | 每房首株成熟植物向两个目标传播 60% 效果 |
| 焦土轮作 | 燃烧 + 扎根 + 收割 | 首次主动收割造成 24 范围伤害并恢复 1/3 种荚进度 |
| 月镜花圃 | 月照 + 湿润 + 扎根 | 每房生成 1 朵可折射友方攻击的镜花 |
| 风中种路 | 孢子 + 扎根 + 收割 | 开启一条单向捷径，回收型攻击伤害 +15% |

配方效果、缺少标签和影响房间必须在地图侧栏直接显示；首轮不测试要求玩家自行背诵的隐藏配方。

## 10. 难度曲线

房间威胁值建议：

`房间威胁 = 基础区域值 + 已清房数 × 0.7 + 精英修正 + 路线风险修正`

不建议让敌人生命无限随时间增长。区域内主要增加敌人组合复杂度；跨区域时普通敌人生命可提升 20%–30%，同时引入新行为。

不再保留独立“舒缓模式”，避免它与简单难度、积分倍率和排行榜资格形成两套重叠规则。降低战斗压力统一通过“简单”难度实现；瞄准辅助、弹幕亮度、屏幕震动和字体等可访问性选项不影响积分。

三档难度的敌人数量、攻击力、弹幕密度、困难 Boss 第二形态和积分倍率，统一以《多房间关卡与战斗扩展设计方案》第 6、9、16 节为准。本草案只负责房间内部的基础威胁值，不重复维护另一套倍率。

## 11. 数据验证指标

原型测试重点记录：

- 每房耗时、受伤次数、种植次数、成熟率、主动收割率与留根率。
- 每个遗物的选择率、胜率与放弃原因。
- 玩家首次主动利用土地状态的时间。
- 首个协同组合形成的房间序号。
- 首个三节点生态配方形成的房间序号，以及各配方的触发率。
- 根忆节点改变相邻房规则、路线选择和 Boss 行为的次数。
- 玩家查看预报后改变路线、播种、留根或契约的比例。
- 零留根、少量留根和网络成型三类路线的通关率、资源量与 Boss 耗时。
- 玩家能否口述统一构筑标签、收割/留根代价与 Boss 继承关系。
- Boss 各招式命中率与玩家识别描述。
- 失败后再次开局率，以及玩家自述的失败原因。

首轮目标区间：

| 指标 | 目标 |
|---|---:|
| 普通房平均耗时 | 45–65 秒 |
| 首区单房平均受伤 | 0.25–0.5 点 |
| 种下植物的成熟率 | 60%–80% |
| 成熟植物主动收割率 | 40%–65% |
| 平均留根率 | 25%–75% |
| 首次形成基础协同 | 第 3–5 个房间 |
| 首次形成三节点生态配方 | 第 4–6 个房间 |
| 网络影响相邻房 | 每关至少 1 次 |
| 网络影响路线选择 | 每关至少 1 次 |
| Boss 可见继承网络 | 使用网络的对局 100% 发生 |
| 零留根与网络成型路线通关率差 | 不超过 15 个百分点 |
| 正确说明收割/留根代价的玩家 | ≥80% |
| 首次挑战 Boss 胜率 | 30%–45% |

数值超出范围时先调整前摇、移动路线、标签反馈、天气预报和收割/留根收益，再考虑直接修改生命或伤害。若月根网络只提高数值却没有改变房间、路线或 Boss，判定为机制未通过，不能用增加特效或奖励数量掩盖。
