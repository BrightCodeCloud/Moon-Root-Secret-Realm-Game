## 6. 开发接入规则

- 所有透明 PNG 使用 `Nearest` 过滤，关闭 Mipmaps、Repeat 和有损压缩。
- 图集是美术源板，需要在接入时切成 `AtlasTexture`、独立 PNG 或重新打包的小型运行时图集。
- 1254×1254 的 4×4 图集是语义网格，不建议直接假设整数等分的 `Hframes=4`；应使用明确区域或先重新打包。
- UI 面板需要在接入时制作九宫格安全区域，不要整体拉伸边角花纹。
- 子弹碰撞体应小于发光外轮廓；激光碰撞体只覆盖高亮核心。
- 攻击预警贴图不负责伤害，伤害窗口由独立计时器控制。
- 门、宝箱、传送门、祭坛和陷阱使用状态机驱动，不要把状态判断写进动画回调。

## 7. 应由代码或着色器完成的效果

以下效果不需要继续生成大量图片：

- 玩家与敌人的受击闪白、无敌闪烁。
- 屏幕震动、短暂停顿、镜头缩放和暗角。
- 血条填充、缓动、延迟损血条和低血量闪烁。
- 伤害数字、暴击数字和治疗数字。
- 激光长度、宽度、滚动纹理、颜色和辉光。
- 预警区域的收缩、旋转、闪烁和透明度。
- 子弹尾迹、少量环境粒子和碎屑散射。
- 调色、Boss 阶段变色与关卡整体光照。

## 9. 仍需在开发过程中完成的生产任务

图片层面的概念、占位和生产锚点已经足够启动春季垂直切片。以下工作需要在实际像素网格、动画和引擎接入阶段完成，不能用高分辨率概念图替代：

1. 按固定网格清稿莱芽、4 种普通敌人和灯笼南瓜王的运行时动画。
2. 将春季模块板制作成真正无缝的 16×16 Tileset，补齐内外角、碰撞层和遮挡层。
3. 将 1254/1448 图集重打包为整数单元格运行时图集，并记录 AtlasTexture 区域。
4. 为 UI 面板制作九宫格安全区，为图标生成 16/24/32 px 实际版本。
5. 选择并记录可商用中文字体授权；在字体确定前使用系统字体占位。
6. 制作攻击、播种、收割、受伤、危险预警、门和 UI 的音效，以及春季环境循环与 Boss 音乐。
7. 在 Godot 中完成色觉、缩放、不同分辨率、手柄焦点与弹幕可读性检查。

这些任务不再缺少视觉方向或动作关键姿势，可以伴随垂直切片开发逐项清稿，不需要继续生成更多同类概念图。
