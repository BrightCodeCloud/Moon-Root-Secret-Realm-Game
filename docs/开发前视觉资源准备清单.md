## 6. 开发接入规则

- 所有透明 PNG 使用 `Nearest` 过滤，关闭 Mipmaps、Repeat 和有损压缩。
- 图集是美术源板，需要在接入时切成 `AtlasTexture`、独立 PNG 或重新打包的小型运行时图集。
- 1254×1254 的 4×4 图集是语义网格，不建议直接假设整数等分的 `Hframes=4`；应使用明确区域或先重新打包。
- UI 面板需要在接入时制作九宫格安全区域，不要整体拉伸边角花纹。
- 子弹碰撞体应小于发光外轮廓；激光碰撞体只覆盖高亮核心。
- 攻击预警贴图不负责伤害，伤害窗口由独立计时器控制。
- 门、宝箱、传送门、祭坛和陷阱使用状态机驱动，不要把状态判断写进动画回调。

## 7. 应由代码或着色器完成的效果

以下效果不需要继续生成大量图片：

- 玩家与敌人的受击闪白、无敌闪烁。
- 屏幕震动、短暂停顿、镜头缩放和暗角。
- 血条填充、缓动、延迟损血条和低血量闪烁。
- 伤害数字、暴击数字和治疗数字。
- 激光长度、宽度、滚动纹理、颜色和辉光。
- 预警区域的收缩、旋转、闪烁和透明度。
- 子弹尾迹、少量环境粒子和碎屑散射。
- 调色、Boss 阶段变色与关卡整体光照。
